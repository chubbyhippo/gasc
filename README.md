# gasc

## Install

### systemd Linux

```sh
curl -fsSL https://raw.githubusercontent.com/chubbyhippo/gasc/refs/heads/main/systemd/setup.sh | sh
```

### macOS (run as root)

```sh
curl -fsSL https://raw.githubusercontent.com/chubbyhippo/gasc/refs/heads/main/mac/setup.sh | sudo sh
```

### Windows, from WSL / Git Bash / MSYS

```sh
curl -fsSL https://raw.githubusercontent.com/chubbyhippo/gasc/refs/heads/main/wins/setup.sh | sh
```
